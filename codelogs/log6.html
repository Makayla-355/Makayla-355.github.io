Code References

What did you look up?

I looked up the CSS property display, since it's something I've been using a lot for layout but still wanted a clearer understanding of how all the values work.

What sites did you consult?

  • W3Schools
  • Mozilla Developer Network (MDN)
  • CSS-Tricks
  • GeeksforGeeks

What are the differences in the information presented?

All four sites explain the same core idea of the display property, but they do it in pretty different ways. W3Schools is very straightforward and beginner-friendly, with short definitions and simple examples, but it doesn't go super in-depth. MDN is a lot more detailed and technical, explaining how each value works in the browser and how it interacts with layout systems like flexbox and grid. CSS-Tricks feels more practical with explanations that connect directly to real-world use cases, which made it easier to understand when I would actually use each value. GeeksforGeeks is kind of in between. It explains the concepts clearly and includes examples, but it feels more like a textbook explanation.

What features should a code reference page offer?

I think a good code reference page should have clear definitions, multiple examples, and show real use cases. It also helps when there are visuals or diagrams, especially for layout properties like display. Organization matters too, since most of the time I' trying to find something quickly while coding. Having notes about common mistakes or browser behavior would also be really useful.

Do any resources stand out?

MDN definitely stands out as the most reliable and detailed, especially when I want to fully understand something. CSS-Tricks is probably my favorite for actually learning how to use things in practice. W3Schools is helpful when I need a quick answer, but I wouldn't rely on it for deeper understanding. GeeksforGeeks is solid, but it didn't stand out as much compared to the others.

Code Log 5:Images

Images can be added to a webpage either with the HTML tag or by using the CSS background-image property. The tag places the image directly in the HTML as part of the page’s content, like the photo of my cookies on the recipe page. Because it is part of the content, it can include things like alt text and it moves with the layout. A background image is added through CSS and sits behind an element instead of being its own object. Background images are usually used for decoration or layout rather than important content. Besides background-image, other CSS properties affect how background images appear. For example, background-size controls how the image fits inside the element, and background-repeat determines whether the image repeats across the background or only appears once. Another useful property is background-position, which controls where the image is placed within the element. Dimensions and resolution both describe image quality, but they are different. Dimensions refer to the width and height of an image in pixels, while resolution refers to how many pixels are packed into the image, which affects how sharp it looks. GIF, PNG, JPG/JPEG, WebP, and SVG are different image file formats used on the web. JPGs are commonly used for photos because they compress the file size well. PNG files keep more detail and support transparency, which makes them good for graphics and logos. GIFs support simple animations but have limited colors. WebP is a newer format that keeps good quality while making files smaller. SVG is different because it is a vector format, meaning it can scale to any size without losing quality, which makes it great for icons and logos.
